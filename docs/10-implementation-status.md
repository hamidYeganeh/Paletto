# پالتو: راهنمای نسخه پیاده‌سازی‌شده

این سند وضعیت کد اجراشده را توضیح می‌دهد. اسناد 00 تا 09 چشم‌انداز گسترده‌تر محصول هستند و نباید به معنی اجرای تمام موارد آن‌ها تلقی شوند.

## اجرا

مسیر واقعی پروژه: `/Users/mahdi/Documents/projects/paletto`.

```sh
npm install
npm run dev --workspace web
```

برای پیش‌نمایش با داده‌های مشخصاً نمونه:

```sh
npm run dev:demo --workspace web
```

مسیر `/explore` ورودی قابلیت‌های کاربردی است. صفحه اصلی موجود حفظ شده و به کشف هنر، رویدادها و فضای کاری متصل است. `/gallery/demo` سالن سه‌بعدی بازطراحی‌شده است. `/design-system` راهنمای بصری است.

بدون `MONGODB_URI`، محیط توسعه داده را در `apps/web/.data/paletto.json` نگه می‌دارد. این فایل خصوصی است و نباید در گیت ثبت شود. داده نمونه فقط هنگام ساخت یک ذخیره‌ساز جدید و با `PALETTO_DEMO=true` ساخته می‌شود. داده‌های نمونه نشان‌دهنده همکاری با گالری واقعی نیستند. برای پایگاه واقعی از حالت نمونه استفاده نکنید.

## گردش‌های اجرایی

- ثبت‌نام، ورود با نشست HttpOnly، خروج، ویرایش پروفایل و تغییر رمز؛ تغییر رمز نشست‌های دیگر را می‌بندد.
- گالری/اثر/رویداد: پیش‌نویس → انتظار بررسی → منتشرشده یا نیازمند اصلاح.
- نمایشگاه، تور، ورکشاپ، نشست، پرفورمنس و فراخوان در مدل رویداد هستند. هر سانس به‌صورت یک رویداد با زمان و ظرفیت مستقل ثبت می‌شود.
- گالری با شهر، نوع، رشته، ساعت، روز تعطیل و مختصات جست‌وجو می‌شود. «اکنون باز است» از ساعت تهران محاسبه می‌شود؛ تعطیلی موردی نیاز به به‌روزرسانی اطلاعات دارد.
- رزرو دارای کلید تکرارناپذیری است؛ مجموع رزروهای فعال نمی‌تواند از ظرفیت یا موجودی عبور کند.
- رزرو پرداخت‌نشده ۱۵ دقیقه معتبر است. انقضا در مراجعه بعدی به API اعمال می‌شود.
- بلیت رایگان مستقیماً تأیید می‌شود. بلیت پولی فقط بعد از تأیید سمت سرور درگاه تأیید می‌شود.
- بلیت در بازه یک ساعت پیش از شروع تا پایان رویداد، تنها یک‌بار و برای کل تعداد همان سفارش پذیرش می‌شود.
- لغو رویداد سفارش‌های رایگان را لغو و سفارش‌های پرداخت‌شده را وارد صف استرداد می‌کند.
- استرداد فعلاً توسط اپراتور در مسیر بانکی انجام می‌شود و شماره واقعی پیگیری در اپ ثبت می‌شود؛ دکمه ثبت استرداد وجهی منتقل نمی‌کند.
- سفارش اثر پس از پرداخت در صف ارسال فروشنده است؛ فروشنده کد حمل را ثبت می‌کند و خریدار دریافت را تأیید می‌کند.
- درخواست همکاری، استعلام، سفارش ساخت اثر و پشتیبانی دارای صندوق پیام و پاسخ هستند؛ قرارداد مرحله‌ای سفارش ساخت و پرداخت امانی پیاده نشده‌اند.
- دنبال‌کردن و ذخیره‌سازی در حساب، برنامه شخصی بازدید و تازه‌های هنرمندان/گالری‌ها.
- کمپین با کد یکتا، درصد، تاریخ پایان، محدودیت استفاده، لینک UTM، ثبت بازدید یکتای روزانه، شمارش رزرو تأییدشده، توقف کمپین، متن معرفی و خروجی CSV.

## دیزاین سیستم

`features/platform/platform.css` توکن‌های کاغذ، جوهر، تأکید، سطح، متن ثانویه، فاصله و شعاع را تعریف می‌کند. فونت همان ایران‌سنس متغیر صفحه اصلی است. دکمه‌ها، فیلدها، وضعیت‌ها، فرم‌ها، پنل، بلیت و ناوبری از کلاس‌های مشترک استفاده می‌کنند. کاهش حرکت، نمای سبک آثار، فوکوس قابل مشاهده، برچسب فرم، RTL و اندازه موبایل پوشش داده شده‌اند.

سالن مجازی با Three.js ساخته شده: دیوار، کف، سقف، ریل نور، قاب، شناسنامه و دوربین اول‌شخص. گردش آزاد با WASD یا جهت‌نما، چرخاندن نگاه با کشیدن ماوس/لمس یا Q/E، کنترل‌های نگه‌داشتنی موبایل، نقشه موقعیت و بازگشت به ورودی دارد. عبور از دیوارها محدود می‌شود. خارج‌شدن فوکوس یا قطع لمس، حرکت را متوقف می‌کند؛ حرکت دستی تور خودکار را قطع می‌کند. چهار ظاهر سالن وجود دارد. تصاویر با نسبت واقعی خود نمایش داده می‌شوند. این سالن بازسازی دقیق بنای واقعی یا نمایش تضمین‌شده ابعاد فیزیکی نیست؛ برای آن باید پلان و اندازه اثر وارد شود. مدل سه‌بعدی مجسمه، صوت راهنما و واقعیت افزوده هنوز وجود ندارد.

## معماری و راه‌اندازی واقعی

Turborepo و Next.js موجود حفظ شده‌اند. API در Route Handlerهای Next و خدمات دامنه جدا قرار دارد. NestJS اضافه نشده؛ کاربر این فناوری را اختیاری اعلام کرده بود و برای این نسخه نیاز به سرویس دوم نبود.

MongoDB از مجموعه‌های جدا و تراکنش snapshot/majority استفاده می‌کند؛ **replica set لازم است**. تراکنش‌ها برای حفظ موجودی با سند revision هماهنگ می‌شوند. این طراحی برای حجم اولیه است: بارگذاری کل حالت و قفل سراسری تراکنش نیازمند بازطراحی به پرس‌وجوهای صفحه‌بندی‌شده و تراکنش‌های محدود پیش از ترافیک زیاد است. مسیر فایل توسعه فقط برای یک فرایند محلی است.

متغیرهای محیطی نمونه در `apps/web/.env.example` هستند. برای انتشار:

- `MONGODB_URI` و `MONGODB_DB` را تنظیم کنید.
- `APP_ORIGIN` باید دامنه HTTPS واقعی باشد؛ هم اعتبارسنجی Origin و هم callback درگاه به آن متکی‌اند.
- `PALETTO_MEDIA_ROOT` باید روی فضای پایدار باشد؛ برای چند نمونه اپ، حجم مشترک لازم است.
- مرچنت معتبر را در `ZARINPAL_MERCHANT_ID` قرار دهید. مقادیر سفارش تومان‌اند و به ریال برای درگاه تبدیل می‌شوند.
- گالری‌های واقعی باید اطلاعات و همکاری خود را تأیید کنند و مدیر قبل از انتشار بررسی کند.
- برای مدیر، `PALETTO_ADMIN_EMAIL` و `PALETTO_ADMIN_PASSWORD` را امن در محیط فرایند قرار دهید و `npm run admin:bootstrap --workspace web` را اجرا کنید. هیچ حساب مدیر پیش‌فرض یا رمز مشترک وجود ندارد. سپس این متغیرها را حذف کنید.
- برای پراکسی یا چندنمونه‌ای شدن، محدودیت نرخ توزیع‌شده، پشتیبان‌گیری، نظارت و سیاست نگهداری داده لازم است.

```sh
npm run build
npm run start --workspace web
```

Webpack برای جلوگیری از مشکل کش Turbopack در محیط فعلی استفاده می‌شود. `PALETTO_DISABLE_BUILD_CACHE=true` گزینه اختیاری دستگاه کم‌فضاست.

## مرز تحویل

پیاده‌سازی محلی به معنی راه‌اندازی تجاری نیست. موارد زیر انجام نشده‌اند:

- اتصال به حساب واقعی درگاه و آزمون بانکی واقعی، واریز خودکار به گالری یا تسویه چندذی‌نفعی؛
- ارسال واقعی ایمیل/پیامک/پوش و اتوماسیون ارسال کمپین؛ ابزار کمپین فعلی لینک و متن می‌سازد و عملکرد را ثبت می‌کند؛
- بازیابی رمز با ایمیل و تأیید مالکیت ایمیل/موبایل؛
- امضای قرارداد، بررسی اصالت توسط کارشناس، حراج، بازار ثانویه و مدیریت جامع مجموعه خصوصی؛
- زمان‌بندی چندسانسی در یک رکورد، مسیریابی بهینه چندگالری و بلیت ترکیبی؛
- طراحی/مدل‌سازی سه‌بعدی دقیق گالری‌های واقعی، AR و تور صوتی؛
- انتشار عمومی اپ و ورود فهرست تأییدشده گالری‌های سراسر ایران.

## بررسی و آزمون

آزمون خدمات در `apps/web/tests/platform.test.ts` مستقل از داده واقعی اجرا می‌شود و ظرفیت هم‌زمان، نقش، حفظ حریم خصوصی، انتشار، کد تخفیف، لغو، همکار پذیرش و پرداخت با پاسخ شبیه‌سازی‌شده را پوشش می‌دهد. همان مسیرها روی MongoDB replica set محلی اجرا شده‌اند.

```sh
PALETTO_DATA_FILE=/tmp/paletto-test-unique.json npm run test --workspace web
npm run test:e2e --workspace web
npm run typecheck
npm run lint
```

پیکربندی Playwright فعلی از Chrome نصب‌شده روی macOS استفاده می‌کند؛ برای CI مسیر مرورگر را با Chromium نصب‌شده جایگزین کنید. فایل آزمون مرورگر در `/tmp/paletto-test-browser.json` داده نمونه جدا نگه می‌دارد.

در بررسی نهایی ۱۰ سپتامبر ۲۰۲۶، بیلد انتشار و TypeScript موفق شدند؛ ۱۳ آزمون خدمات روی MongoDB replica set مستقل و ۸ آزمون Chrome موفق شدند. آزمون مرورگر ناوبری صفحه اصلی در عرض ۳۶۰ پیکسل را هم پوشش می‌دهد. ESLint خطا ندارد و دو هشدار پیشین در GalleryDemoScreen قدیمی و LandingHorizontalGallerySection باقی است. در محتوای EditorialGallery نیز هشدار هدف خالی GSAP مشاهده شد؛ این بخش قدیمی نیاز به بررسی جداگانه دارد. با اجازه صریح کاربر، ممیزی آنلاین اجرا شد و ۹ advisory شامل یک مورد بحرانی گزارش شد. Next.js از 16.2.6 به 16.3.4 ارتقا یافت و ۱۰ بسته غیرمستقیم با npm audit fix به‌روز شدند؛ نتیجه ممیزی پس از اصلاح: صفر آسیب‌پذیری شناخته‌شده در ۷۴۸ بسته بررسی‌شده. این نتیجه تضمین نبودن همه خطاهای امنیتی نیست. مرجع اصلاح Next: https://nextjs.org/blog/august-2026-security-release. وجود آزمون‌ها جایگزین بازبینی امنیتی مستقل پیش از انتشار عمومی نیست.


## تکمیل گردش سه‌بعدی و ممیزی مجاز

در ادامه درخواست کاربر، کنترل گردش آزاد گالری اضافه شد. دو سناریوی جدید مرورگر، جابه‌جایی واقعی دوربین، چرخش نگاه، مرز دیوارها، توقف با خروج فوکوس، قطع تور خودکار و پایان لمس موبایل را بررسی می‌کنند. پس از رفع خطاها، هر دو سناریو و بازدید ساده/سه‌بعدی موفق شدند؛ هفت سناریوی دیگر اپ نیز پس از ارتقای Next موفق بودند. ۱۳ آزمون خدمات دوباره موفق شدند و TypeScript بدون خطا بود. نتیجه npm audit fix پس از ارتقای Next به 16.3.4 صفر آسیب‌پذیری شناخته‌شده است.
